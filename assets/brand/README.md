# Marca MAREMAGNUM

- `maremagnum-logo-original.png`: logo original extraído de la plantilla de traducciones (316 × 143 px, baja resolución). Solo como referencia; no usar en la web.
- `maremagnum-icon.svg`: el icono (círculo con olas) redibujado en vector a partir del original. Es el que se usa en la web.
- `maremagnum-icon-32.png`, `-180.png`, `-512.png`: favicon, icono de iPhone (apple-touch-icon) e icono grande.

Reglas:
- El nombre se escribe siempre junto y en mayúsculas: **MAREMAGNUM**.
- Color de marca: **#1498D5**.
- El nombre va siempre a la derecha del icono.
- La tipografía del logo original es una sans geométrica (tipo Montserrat SemiBold), con espaciado amplio y una sombra desplazada en azul claro.
